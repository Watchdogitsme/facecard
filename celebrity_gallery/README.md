Place one or more locally stored reference photos in this folder (JPG, PNG, WEBP, or BMP). Name each file after the celebrity, for example `Example_Name.jpg`; the app measures the ten facial-geometry cues and displays a person only if at least five cues score 70/100 or higher. For multiple images per person, group them in subfolders named for that person and build a median feature card with `python build_gallery.py --source-dir "C:\path\to\labeled_faces"`.

The optional `index.npz` and `references` folder are generated by `build_gallery.py`; they are ignored by Git. Use only images you have permission to process. Facial feature cards and camera frames are processed locally and are not uploaded by the app. Use clear images with one visible face per person. This is a rough geometry-based resemblance heuristic, not a probability or identity verification.

To obtain a starter set from Wikimedia Commons, run `python download_celebrity_gallery.py --count 120 --index`. It keeps only face-detected portraits whose Commons metadata lists CC BY, CC BY-SA, CC0, or Public Domain, and records attribution/source/license details in `attributions.csv`. The script does not guarantee every requested name has an eligible photo; it reports the result and can resume. Review and honor each image's license and attribution requirements.
